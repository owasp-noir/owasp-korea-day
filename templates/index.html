Noir는 소스 코드에서 서비스의 주소(엔드포인트)를 찾아내는 오픈소스 도구예요.

날짜
2026년 11월 28일 (토)
시간
2시간
준비물
GitHub 계정, 노트북
오늘의 목표
내 이름으로 올린 PR 하나
참가자용

시간표

120분 중 실습이 75분이에요. 1부에 올린 PR의 자동 검사 결과를 2부에서 확인해요.

  1. 0:00소개와 시연15분진행자가 PR 하나를 올리는 전 과정을 보여 줘요.
  2. 0:15과제 고르기10분과제 목록에서 하나 골라 댓글을 남겨요.
  3. 0:251부 실습40분가이드를 따라 첫 PR을 올려요.
  4. 1:05쉬는 시간10분이 사이에 자동 검사가 돌아요.
  5. 1:152부 실습35분검사에서 걸린 부분을 고치고 다음 과제로 넘어가요.
  6. 1:50마무리10분검사를 통과한 PR을 현장에서 반영해요.

오기 전에

  • GitHub 로그인. 계정이 없으면 미리 만들고, 2단계 인증까지 끝내 두세요.
  • 노트북과 충전기. 휴대폰으로는 실습하기 어려워요.
  • 설치는 선택. 브라우저 실습은 설치할 게 없어요. 써 보고 제보하기나 코드로 기여하기를 할 분만 Noir를 미리 설치해 오세요.

자주 묻는 질문

코딩을 못 해도 되나요?

네. 브라우저로 기여하기는 룰 파일에 단어와 예시를 추가하는 작업이라 코드를 짜지 않아요.

영어로 써야 하나요?

PR 제목만 영어로 써요. 가이드에 있는 예시를 조금 바꾸면 돼요.

시간 안에 못 끝내면 어떻게 되나요?

PR은 행사가 끝나도 열려 있어요. 같은 PR에서 이어서 고치면 돼요.

기여하면 어디에 남나요?

PR이 반영되면 다음 Noir 버전에 들어가고, 저장소 첫 화면의 기여자 목록에 프로필이 올라가요.

둘이 같이 해도 되나요?

네. 막히면 옆 사람에게 먼저 묻고, 안 풀리면 손을 들어 주세요.

용어가 낯설어요.
엔드포인트
서버가 요청을 받는 주소. /login, /api/orders 같은 것.
PR (풀 리퀘스트)
고친 내용을 반영해 달라고 보내는 요청.
포크
다른 사람의 저장소를 내 계정으로 복사한 것.
머지
보낸 PR이 원본에 반영되는 것.
